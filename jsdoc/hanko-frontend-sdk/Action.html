Action

Represents a single action that can be run from a State. `action` and `href` identify the action for the backend, `inputs` describes the input fields the action accepts (see State#actions for how these map to a concrete state), and `description` is a human-readable summary of what running the action does.
Properties:
Name Type Description
action string The unique name of the action within the current flow.
href string The URL the action is submitted to when run.
inputs TInputs The input fields accepted by the action.
description string A human-readable description of the action.
